# Політика конфіденційності FastChecker

Дата набрання чинності: 26 жовтня 2026 року.

Видавець: **MrMikhalych**. Контакт з питань конфіденційності: **mykhail.development@gmail.com**.

Ця політика описує обробку даних розширенням FastChecker. FastChecker допомагає авторизованим користувачам Back Office (БО) переглядати інформацію про клієнтів у межах доступу їхньої робочої сесії.

## Які дані обробляються

- Введений користувачем ID клієнта, адреса електронної пошти або номер документа для пошуку.
- Інформація, яку повертає API БО: результати пошуку клієнтів, номер документа, дати та тип самовиключення (тайм-аут або SelfExclusion), ліміти часу та грошових витрат, залишки, можливості акаунта, нотатки та записи бонусів за верифікацію. Відповідь пошуку БО може містити додаткові персональні та облікові поля; у список вибору розширення передає лише ID та email. Прихований БО email не розкривається розширенням.
- Токен поточної авторизованої сесії БО, потрібний для виконання запитів. Розширення читає його зі сховища БО у вкладці браузера; воно не запитує пароль і не показує токен у своєму вікні.

## Для чого використовуються дані

Дані використовуються для пошуку вибраного клієнта, отримання та відображення його інформації після дії користувача. За окремим натисканням кнопки розширення записує текст із залишками часу до системного буфера обміну. Вміст буфера обміну розширення не читає.

## Куди передаються дані

Розширення працює у відкритій вкладці `https://backoffice.betconstruct.com` і надсилає запити лише до `https://backofficewebadmin.betconstruct.com` через HTTPS. Параметри пошуку та токен сесії передаються до API БО для виконання запитів. Браузер також може додавати відповідні cookies; розширення не читає їх через API cookies.

Видавець не отримує ці дані на власний сервер. Розширення не містить аналітики, реклами, телеметрії або передавання даних рекламним сервісам. Дані не продаються і не використовуються для кредитного скорингу чи цілей, не пов’язаних із заявленою функціональністю.

Обробка та зберігання інформації самим БО, включно з можливими серверними журналами запитів, регулюються правилами відповідного оператора БО. Ця політика не змінює їх.

## Зберігання та видалення

FastChecker не записує отримані дані або токени у файли, постійне сховище розширення чи синхронізацію браузера. Результати тимчасово знаходяться в пам’яті під час роботи вікна розширення. Закриття вікна припиняє зберігання результатів у цьому вікні; кнопка очищення прибирає показані результати та введене значення.

Текст, який користувач скопіював, може залишатися в системному буфері обміну або його історії відповідно до налаштувань операційної системи. Користувач може очистити його самостійно. Розширення не видаляє дані клієнта на сервері БО та не змінює збереження сесії самим БО.

Для виправлення або видалення інформації в БО необхідно звертатися до оператора відповідної системи. Для питань щодо обробки даних самим розширенням звертайтеся до видавця за вказаною контактною адресою.

## Дозволи та захист

Дозвіл `scripting` і доступ до домену БО потрібні для виконання коду розширення у відкритій вкладці БО після дії користувача. Розширення використовує наявну авторизацію і не надає додаткових серверних прав доступу. Токен не повертається у вікно розширення. Запити використовують HTTPS; виконуваний код постачається у складі розширення, а не завантажується з віддаленого сервера.
